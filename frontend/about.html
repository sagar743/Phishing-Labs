How It Works

Phishing Labs analyzes a URL in four layers

1. Client Layer

You enter a URL in the browser. This page sends it to the backend for analysis.

2. Feature Extraction Layer

The backend breaks the URL down into 10 numeric features - length, dot count, hyphen count, HTTPS presence, IP address presence, and more.

3. Model Inference Layer

A Random Forest classifier, trained on a labeled dataset of phishing and legitimate URLs, uses those features to predict a class and a probability.

4. Response Layer

The prediction, risk score, confidence, and a plain-language explanation are sent back as JSON and displayed on the Result page.

Note: this model is trained on a representative dataset for educational purposes. It is not 100% accurate and HTTPS alone does not guarantee a site is legitimate. See the README for exact evaluation metrics.
